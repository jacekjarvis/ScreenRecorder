# UX reference — matching FlashBack Pro 5

Goal: someone who uses FlashBack Pro 5 can use this app without relearning it.
Same layout, menus and workflow; **blue** accent instead of FlashBack's purple; our own icons
(Segoe Fluent Icons) and artwork.

## Theme
- Dark UI: window background ~#2B2B2B, menu bar a lighter grey band, thin separators between sections.
- Accent: blue (#2F7FE0 family) where FlashBack uses purple (title icon, selection, toolbar).
- Record button: grey button with a red dot.

## Recorder main window (small, fixed size)
- Title bar: app icon, "ScreenRecorder", minimise and close.
- Menu band: **Recordings**, **Set Timer**, **Settings**, **Help ▾** on the left; **Video Editor** on the right.
- Rows, separated by lines:
  1. Monitor icon · **Area** · dropdown: Full screen / Window / Region (+ one entry per monitor when there are several).
  2. Mic icon · ☐ **Microphone**; speaker icon · ☐ **PC Sounds** (device choice and level in Settings).
  3. Webcam icon · ☐ **Webcam**.
- Bottom: **Record** button.

## Choosing what to record
- **Window**: after choosing Window, click the window to record; a red frame marks it.
- **Region**: a red frame appears that you move and resize, then press Record.
- Region and window may span monitors; anything outside every monitor is black.

## While recording / minimised
- Minimise to the **tray** or to a small **floating toolbar** (drag handle, Record, Stop, Pause, menu ▾).
- Tray / ▾ menu: Open main window, Record, Stop, Add marker, Restart recording, Help,
  Minimise to tray / floating controls, About, Exit.
- **Hotkey** pops up the recording controls window: Stop, Pause/Resume, Restart.
- **Add marker** pauses recording and asks for a marker name.

## Set Timer (scheduled recording)
- "Use scheduling" on/off, start-at time, stop-at time **or** duration.
- After the scheduled recording runs, scheduling switches itself off.

## Settings (tabbed window)
Window · Video · Sound · Webcam · Display · Keystrokes · Hotkeys · File Size · Record-time Notes

- **Display**: hide desktop icons while recording.
- **Keystrokes**: capture keystrokes; replace password characters with asterisks.
- **File size**: unlimited, or stop when the recording reaches N MB.
- **Record-time notes**: move the mouse to a chosen screen edge to open a note window;
  optionally pause while it's open; optionally save when the cursor leaves it.
